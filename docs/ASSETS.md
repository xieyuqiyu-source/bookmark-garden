# 素材与字体

- 云海壁纸：来自本项目已确认的 Figma A 云屿设计中的独立背景图片；本地文件 `public/assets/main/img.png`。
- 界面图标与演示品牌图标：从同一 Figma 文件导出。Google 日历使用创建原设计时的同一份 SVG 源文件。品牌名称及商标归各自权利人所有，图标用于识别演示书签对应的网站。
- 真实扩展的网站图标：Chrome 内置 favicon API，加载失败时显示标题首字。
- 补充交互图标：项目已有的 Lucide React，ISC 许可。
- 中文字体：Noto Sans SC Variable；时间字体：Inter Variable。均通过 Fontsource 包随应用打包，使用 SIL Open Font License 1.1，许可证副本见[`public/licenses/`](../public/licenses/)（随安装包一起提供）。

应用不在运行时请求 Figma 临时下载地址或远程字体服务。设计素材不构成对品牌商标的重新授权。
