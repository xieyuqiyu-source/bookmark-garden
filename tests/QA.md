# 验证范围

自动化入口和运行步骤见 README。

- `model.test.ts`：层级、空文件夹、过滤排序、安全协议、旧偏好迁移、新外观字段边界、5000 条完整性、文件夹分组不重复。
- `browser_test.py`：网页预览与生产扩展两个阶段。后者仅使用自动创建的临时浏览器配置和测试书签。
- 预览阶段：搜索/空结果/清空/快捷键；固定与取消及刷新；嵌套模态框焦点；设置持久化；图片类型校验、上传与恢复默认；五档窗口无横向溢出；离线资源和页面异常。
- 扩展阶段：原生空书签、新增/改名/移动/删除刷新；嵌套空文件夹；危险协议禁用；固定不更改原树；跨标签偏好；存储失败回退；文件夹与搜索分页；新标签覆盖；生产 CSS 的壁纸绝对地址及图片加载。
- 视觉检查：桌面、设置、搜索、空搜索、书签菜单、文件夹、窄屏与深色截图。

边界：自动化使用 Chrome for Testing；用户常用 Chrome 的企业策略、其他扩展冲突及 Chrome 商店发布流程未涵盖。

- 1.1.2：无三点按钮、右键及 Shift+F10、排序菜单选中状态/方向键/回车、动画关闭后焦点恢复、减少动态效果、隐藏滚动条后的纵向及横向滚动。
