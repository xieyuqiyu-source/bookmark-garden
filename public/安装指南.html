让书签住进你的新标签页。

只需安装一次。之后打开新标签页，就能看到自己的书签桌面。

  1. 在 Chrome 地址栏输入 chrome://extensions/。
  2. 开启右上角的「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择项目内的 dist 文件夹。若使用 ZIP 安装包，请先解压，选择含 manifest.json 的文件夹。
  4. 打开新标签页；如果 Chrome 询问是否保留更改，选择保留。

启动 Chrome 时也打开栖页

打开 Chrome「设置 → 启动时」，选择「打开新标签页」。若设置为继续浏览上次打开的网页，Chrome 会恢复原来的标签。

让浏览器更清爽

可用 macOS 的 ⌘⇧B，或 Windows/Linux 的 Ctrl+Shift+B 切换书签栏显示。

数据和权限

扩展读取本地书签和 Chrome 网站图标；固定、外观等偏好保存在本机。没有账号、服务器或统计脚本。扩展不修改或删除原始书签。Chrome 会为 bookmarks 权限显示包含修改能力的提示，但此扩展只调用读取接口。

普通网页预览只能显示示例。安装后才会通过 Chrome 扩展权限访问真实书签。

更新安装包

关闭栖页标签页，将新版 ZIP 全部内容覆盖解压到原安装目录。在 chrome://extensions/ 点击栖页的刷新按钮，再打开新标签页。请保留原安装目录，不要先卸载扩展，以免丢失本地偏好。

过渡动画

动画默认跟随系统设置。如果系统开启了「减少动态效果」，可在栖页「设置 → 过渡动画」中独立开启；恢复默认会重新跟随系统。

遇到问题

没有接管新标签页：检查是否启用其他新标签页扩展。隐身模式的新标签页不能被接管。更新版本后，在扩展管理页点击刷新，再重新打开新标签页。
